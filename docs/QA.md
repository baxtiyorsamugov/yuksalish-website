# Проверка публичного сайта

Дата: 20 октября 2026 года. Среда: Windows, локальный PHP, headless Microsoft Edge.

## Автоматически проверено

- PHP 8.4.26: синтаксис всех PHP-файлов и `tests/content.php`. Проверены четыре языка интерфейса, наличие тел статей, источники, локальные изображения, PDF, корректный выбор перевода и ошибка чтения данных.
- 153 проверки публичных маршрутов и 301-перенаправлений на четырёх языках. Дополнительно: неизвестные ID и регионы, вложенные несуществующие пути, попытка доступа к данным вне public, массивы вместо параметров, длинная Unicode-строка и экранирование поискового запроса.
- Полный первоначальный пакет из 16 браузерных тестов прошёл на PHP 8.5.11. После добавления оглавления без исходных подзаголовков прошли пять затронутых проверок; отдельный повтор проверил финальные скриншоты. В текущем пакете 17 уникальных тестов.
- Геометрия: 25 страниц × четыре языка × пять ширин (360, 390, 768, 1280, 1440), всего 500 открытий. Нет горизонтальной прокрутки и обрезания заголовков. Дополнительные 20 проверок длинной статьи с рабочими якорями.
- Фильтры, поиск, пагинация, пустая выдача, клавиатура, Escape, меню на телефоне, сохранение материала при смене языка, уведомление об отсутствии перевода, работа без JavaScript, reduced motion и ранний сбой загрузки изображения.
- axe: WCAG 2 A/AA и WCAG 2.1 AA на всех 25 представителях шаблонов. Это автоматическая проверка, не сертификация доступности.
- Изолированный сценарий без файла данных вернул локализованную 503 с повтором загрузки без вывода stack trace. Рабочий каталог не изменялся.
- Проверено покрытие ЎўҚқҒғҲҳ и узбекских апострофов во всех пяти начертаниях локальных шрифтов.
- Конфигурации обоих Docker Compose прошли `config -q`. Локальный Docker daemon не запускался; контейнерный запуск и тест БД выполняются в GitHub Actions.
- При загрузке страниц нет внешних сетевых запросов и JavaScript-исключений. Ссылки на первоисточники, карты и контакты открываются только по действию посетителя.

## Визуально проверено агентом

В браузере просмотрены главная и статья. Дополнительно просмотрены 50 снимков всех 25 представителей на ширинах 390 и 1280 через обзорные листы, а также полная главная, каталог проектов и мобильный первый экран. Проверены иерархия, отступы, читаемость, сохранность фотографий и согласованность компонентов. Это визуальная проверка агентом; пользовательское согласование дизайна ещё не проводилось.

Снимки для ревью: `docs/screenshots/`. Полная локальная матрица и отчёт находятся в игнорируемом `artifacts/`. В CI полный актуальный пакет запускается на PHP 8.4/Apache и Chromium; результаты публикуются как artifact `public-site-qa`.

## Практические ограничения

Проверен выбранный публичный контент, не вся старая база. Приём заявок, полная миграция, админка и публикация не выполнялись. Отдельные архивные анонсы и исходные переводы неполны, что обозначено интерфейсом. Производительность в реальной сети и браузеры Safari/Firefox отдельно не измерялись. Старый сетевой стенд не изменялся.
