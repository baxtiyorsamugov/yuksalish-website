# Передача проекта

## Текущее состояние

Ветка `feat/public-rebrand`. Публичный интерфейс PHP с локальными ресурсами и выбранным реальным содержимым. Старый стенд на `192.168.0.140:8089` не изменён. На этой машине отдельный просмотр: `http://127.0.0.1:8090/uz`.

Основные слои: `app/src/ContentRepository.php` получает выбранные материалы; `app/src/templates/` выводит страницы; `app/src/translations.php` хранит четыре языка интерфейса. CSS/JS и изображения находятся в `app/public/assets/`. SQL в шаблонах отсутствует. Новые публичные API не добавлялись.

Внутренние страницы также переработаны локально: `ArticlePresenter.php` готовит оглавление, списки и оценку времени чтения; `templates/article.php` содержит варианты проекта и редакционной публикации. В JSON подготовлены сведения о периоде и аудитории из существующих источников, у двух заголовков проекта 45 нормализован регистр для показа; исходные тексты сохранены. Оглавление на телефоне сворачивается, работает клавиатура и копирование адреса материала без якоря. Скриншоты этой итерации: `artifacts/stories/`.

После замечания о бледных плашках усилено разделение поверхностей. По следующей обратной связи акценты переведены в бирюзовую гамму исходного SVG (#009eb0), функциональные ссылки и кнопки затемнены до #006f7c для контраста. Основной текст использует тёмно-синий цвет логотипа #243b56, фон #ecf1f2, оглавление #dcebed. Контуры панелей плавно исчезают к юго-западу; заливка и клавиатурный фокус сохраняют читаемость. Положение, прозрачность и параллакс Y сохранены, материал и свечение стали бирюзовыми. Просмотрены публичный сайт и экран входа ElevenLabs как дополнительный ориентир. Снимки текущей палитры на 390, 869 и 1440 px: `artifacts/contrast/teal-*.png`. Все изменения по-прежнему локальные.

Карта разделов: о движении / деятельность / проекты / медиа / регионы, отдельное участие. Перенаправления и сохранённые записи перечислены в `legacy-routes.json`. Полный старый архив не перенесён; старые невыбранные ID не подменяются другими материалами.

Главная также содержит непрерывную строку настоящих логотипов партнёров. Общий футер обновлён и содержит паузу анимации; приглашение к участию на главной объединено с ним. Не менять opt-in View Transitions через responsive media queries: это ранее вызывало отмены при смене ширины. Reduced motion пропускает переход через API, обещания ready/finished обработаны. Пересобрать через `npm ci` и `npm run vendor:lenis`. Wheel сглаживается только для fine pointer; touch, якоря, фокус и позиция прокрутки остаются нативными. Reduced motion, пауза, уход/возврат страницы и скрытая вкладка обработаны. Одна `.back-to-top` в layout возвращает к абсолютному scrollY=0; старых кнопок в футере и статьях больше нет. Снимки: `artifacts/navigation-motion/`.

История и bfcache: при повторном pagereveal или navigation.type=back_forward не запускать резервный CSS-вход. Нативный переход может работать при возврате, но scroll restoration остаётся у браузера. Lenis пересоздаётся по фактической позиции; не сбрасывать scrollY при загрузке. Целевые сценарии истории, отмены анимации и единственной кнопки находятся в `tests/browser/navigation-motion.spec.cjs`.

В итерации 21.10.2026 дополнительно исправлен возврат при уходе во время CSS-входа: временный transform больше не участвует в выборе scroll anchor (`.page-enter #main { overflow-anchor: none }`), после animationend класс снимается. Не увеличивать допуск теста истории ради остаточного сдвига; три повтора и полный пакет подтвердили прежнюю позицию.

## Запуск на другом компьютере

1. Получить эту ветку и прочитать `README.md` и `DESIGN.md`.
2. Запустить PHP 8.4+ через `scripts/start-preview.ps1` или использовать существующий Docker Compose. `.tools/` содержит только локальные инструменты текущего компьютера и не передаётся через Git.
3. Выполнить PHP/HTTP/браузерные проверки из README. Runtime-данные, секреты и исходные архивы получать отдельным согласованным способом, не через Git.
