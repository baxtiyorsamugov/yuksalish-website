# Новый сайт Yuksalish

Рабочий репозиторий для переделки публичного сайта на PHP и MySQL/MariaDB.

Исходный архив сайта и экспорт базы остаются вне Git. В архиве есть пароли БД, журналы ошибок и крупные медиафайлы. Не добавляйте архив и его необработанную распаковку в репозиторий.

Текущий состав сайта и ограничения переноса описаны в [аудите старой версии](docs/legacy-audit.md).

При каждом push в `main` и в pull request GitHub Actions проверяет синтаксис PHP и Python, конфигурацию Docker Compose, запуск сайта и соединение с тестовой базой. Исходный архив и дамп в CI не передаются.

## Локальный запуск

1. Скопируйте `.env.example` в `.env` и задайте отдельные локальные пароли БД.
2. Запустите `docker compose up --build -d`.
3. Откройте `http://127.0.0.1:8088`.

Для просмотра с другого компьютера в одной сети укажите в `.env` адрес нужного сетевого интерфейса в `WEB_BIND_IP` и разрешите выбранный порт в брандмауэре только для локальной сети. Порт базы данных наружу не публикуется.

Новая публичная версия включает четыре языка, общие шаблоны, каталоги с поиском и фильтрами, статьи, проекты, регионы, команду, экспертов, мероприятия, публикации и контакты. Выбранные открытые материалы сохранены в `app/src/data/content.json`; источники файлов перечислены в `app/src/data/assets.json`. Для этого этапа MySQL не требуется: доступ к данным изолирован в `ContentRepository`, чтобы подключить согласованную миграцию отдельно.

## Предпросмотр без Docker

Нужен PHP 8.4+. На Windows: `powershell -ExecutionPolicy Bypass -File scripts/start-preview.ps1`. Либо из корня проекта: `php -S 127.0.0.1:8090 -t app/public scripts/preview-router.php`. Откройте `http://127.0.0.1:8090/uz` (также `/uzc`, `/ru`, `/en`). Просмотр доступен только на этом компьютере.

## Проверки новой версии

1. `php tests/content.php` проверяет переводы, содержимое, источники, PDF и ошибки чтения.
2. На запущенном просмотре: `python scripts/check_routes.py`.
3. `npm ci`, `npx playwright install chromium`, `npm test`. На Windows по умолчанию используется установленный Edge; для Chromium задайте `PW_CHANNEL=chromium`.

Браузерные проверки охватывают все шаблоны на пяти ширинах и четырёх языках, клавиатуру, меню, фильтры, отсутствие переводов, ошибки изображений, reduced motion, отсутствие внешних загрузок и WCAG A/AA через axe. Скриншоты и отчёт сохраняются в игнорируемом каталоге `artifacts/`. `BASE_URL` позволяет проверить другой локальный стенд.

Границы этапа, визуальные решения и следующий шаг описаны в [handoff](docs/HANDOFF.md). Реестр прежних адресов: [legacy-routes.json](docs/legacy-routes.json). Полный архив, приём заявок и админка не включены. Неперенесённые записи возвращают настоящую 404; они не перенаправляются на посторонний материал.

## Просмотр старого сайта в локальной сети

Положите исходный архив `idea (3).zip` в корень проекта и выполните `python scripts/prepare_legacy_preview.py`. Копия создаётся в игнорируемом Git каталоге `legacy-site`; его админка и отправка форм отключены. Полный SQL-экспорт загружается отдельно в локальную базу `legacy_reference`, доступную сайту только для чтения. После подготовки запустите `docker compose -f compose.yaml -f compose.legacy.yaml up -d legacy` и откройте порт `8089` по адресу из `WEB_BIND_IP`.
