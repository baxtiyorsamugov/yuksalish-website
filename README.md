# Новый сайт Yuksalish

Рабочий репозиторий для переделки публичного сайта на PHP и MySQL/MariaDB.

Исходный архив сайта и экспорт базы остаются вне Git. В архиве есть пароли БД, журналы ошибок и крупные медиафайлы. Не добавляйте архив и его необработанную распаковку в репозиторий.

Текущий состав сайта и ограничения переноса описаны в [аудите старой версии](docs/legacy-audit.md).

## Локальный запуск

1. Скопируйте `.env.example` в `.env` и задайте отдельные локальные пароли БД.
2. Запустите `docker compose up --build -d`.
3. Откройте `http://127.0.0.1:8088`.

Для просмотра с другого компьютера в одной сети укажите в `.env` адрес нужного сетевого интерфейса в `WEB_BIND_IP` и разрешите выбранный порт в брандмауэре только для локальной сети. Порт базы данных наружу не публикуется.

Сейчас это только проверяемая основа среды. Страницы и работу с данными добавим после согласования карты сайта и полного экспорта базы.
